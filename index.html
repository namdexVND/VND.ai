Kết nối AI thật

Mặc định VND chạy chế độ demo. Nhập endpoint tương thích OpenAI (chat/completions) — ví dụ server proxy Gemini của bạn: https://ten-app.onrender.com/v1/chat/completions.

Key chỉ lưu trong trình duyệt này (localStorage) và chỉ gửi tới endpoint bạn nhập. Đừng dùng máy chung.
Để trống thì dùng model mặc định của server. Tạo ảnh gọi tới /v1/images cùng máy chủ với endpoint chat.
